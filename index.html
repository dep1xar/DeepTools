Возможности

Всё, что обычно ставят отдельно

Каждый раздел закрывает то, ради чего люди обычно скачивают 3-4 разные утилиты.

♻
SmartCleanup
Temp, кэши и шейдер-кэши по категориям, с предпросмотром размера до удаления. Автоочистка по расписанию, деинсталлятор с чисткой хвостов.
⚡
GameBooster
Ultimate Performance в один клик, заморозка фонового Discord/браузера, автозакрепление игры за дискретной GPU, FPS-оверлей с 1% low.
❤
Health Check
Температуры CPU/GPU в реальном времени, алерт «пора чистить кулер», SMART дисков, стресс-тест и бенчмарк до/после.
⭯
Автозагрузка
Рейтинг подозрительности каждой записи автозапуска: без подписи + запуск из Temp + случайное имя — красный флаг с причиной по наведению.
⚙
Службы и телеметрия
Безопасное вкл/выкл служб с описаниями, три обратимых пресета отключения телеметрии Windows — мягко, средне, жёстко.
◉
Инструменты
Кликер и макро-рекордер, скриншотер с аннотациями, менеджер буфера обмена с картинками, стикеры с напоминаниями.
Сравнение

Мы не первые в каждой отдельной нише

Честно: PrivaZer чистит глубже, Afterburner мониторит точнее. Сила DeepTools — в том, что не нужно ставить пять программ ради того, что тут в одной.

Задача DeepTools CCleaner PrivaZer MSI Afterburner
Чистка Temp / кэшей ✓ по расписанию ✓ ✓ глубже (WinSxS) —
Игровой буст / приоритеты ✓ — — частично
FPS-оверлей и 1% low ✓ — — ✓ эталон (RTSS)
Разгон GPU / вольтаж — — — ✓ эталон
Датчики температур ✓ — — ✓ точнее
Удаление bloatware ✓ — — —
Установщик не нужен нужен нужен нужен
Открытый код ✓ — — —
Когда выбрать не DeepTools: нужен разгон GPU с вольтажем и кривыми вентиляторов — берите Afterburner. Нужна максимально глубокая приватность-чистка (WinSxS, следы активности) — берите PrivaZer. Хотите узнаваемый бренд с цифровой подписью — CCleaner. Хотите все базовые твики и мониторинг в одном exe без установки — для этого и есть DeepTools.

Доверие

Прозрачность и удаление

Программа не оставляет следов, кроме одной папки с настройками — и вот всё, что она хранит.

⚠ Почему может ругаться антивирус
DeepTools делает то же, что и настоящие вирусы: повышает права через UAC, правит реестр и службы, шлёт синтетический ввод (кликер) и грузит драйвер для датчиков. Релиз пока не подписан сертификатом — отсюда ложные ML-срабатывания вроде Trojan:Win32/Wacatac.B!ml. Исходный код открыт полностью — можно прочитать и собрать самому.
🗑 Как удалить полностью
1Удалить DeepTools.exe // установщика нет
2Удалить %AppData%\DeepTools // конфиг, логи, заметки
3Снять автозапуск в настройках // если был включён
📄 Что хранится в AppData
Только локально, ничего не отправляется наружу: config.txt (настройки), gametime.log (игровая статистика), temps.log (история температур), clipboard.dat + clipboard_img (буфер обмена), notes (стикеры).
